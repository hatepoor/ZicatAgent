# 裁剪记录

> 文档索引：[docs/README.md](../README.md)

本仓库从上游 ZicatAgent 裁剪而来，只保留 Agent 内核。本文记录**删了什么、为什么删、删的时候动了哪些代码**，便于后续追溯或恢复。

## 1. 裁剪结果

| 指标 | 上游 | 现在 |
|---|---|---|
| Python 文件 / 行数 | ~220 / 约 42,000 | 33 / 约 9,800 |
| 仓库体积 | 约 27 MB | 约 1.4 MB |
| 目录数 | 11 | 7（assets / core / engine / memstore / docs / memory / reflect / temp + 根） |

## 2. 删除清单

## 前端（37,794 行，91% 的代码）

`frontends/` 整目录：Qt GUI（`qtapp.py`）、Streamlit（`stapp.py` / `stapp2.py`）、TUI 三代（`tuiapp.py` / `tuiapp_v2.py` / `tui_v3.py`）、桌面桥（`desktop_bridge.py`）、Hub 与手机配对（`hub.py` / `hub.html` / `hub_p2p.py` / `p2p_ws_client.py`）、7 个 IM 机器人（Telegram / QQ / 飞书 / 企微 / 钉钉 / 微信 / Discord）、桌面宠物、8 套皮肤、18 个前端测试，以及 `hub.pyw`、`launch.pyw`。

## 发布与营销资源

`docs/`（上游安装文档）、`assets/demo/`（19.4 MB 演示 gif）、`assets/images/`（1.1 MB 配图）、技术报告 PDF（3.1 MB）、`assets/supergrok_proxy.py`（零引用）、`assets/tools_schema_cn.json`（消费者已删）、`assets/configure_mykey.py`（前端时代的配置向导，内嵌 7 个 IM 平台的 `from frontends.*` 依赖）、`zicat_cli/` + `zicat.cmd`（前端命令分发器）、安装脚本、`CONTRIBUTING.md`。

## 3. 保留但"搬了家"的东西

上游把这些纯后端逻辑放在 `frontends/` 里，裁剪时抽到 `core/`：

| 新位置 | 来源 | 作用 |
|---|---|---|
| `core/modes.py` | `frontends/slash_cmds.py` | `/goal` `/team` `/autorun` `/morphling` 等模式入口的提示词构造 |
| `core/plan_state.py` | `frontends/plan_state.py` | 计划模式状态机 |
| `core/cost_tracker.py` | `frontends/cost_tracker.py` | 按线程统计 token 用量 |
| `core/rewind.py` | `frontends/worldline.py` | checkpoint 树 + 文件改动回退 |
| `core/session_restore.py` | `frontends/continue_cmd.py` | 会话列表、解析、恢复 |
| `core/review.py` | `frontends/review_cmd.py` | `/review` 提示词与命令解析 |
| `core/commands.py` | 新增 | 斜杠命令分发，把上面这些接到 CLI（`/review` `/continue` `/cost` `/plan` `/scheduler` 等） |

> P5 之后：`core/cost_tracker.py` 与 `core/session_restore.py` 已删除（`/cost` 改用 graph 用量，
> 文本日志恢复下线）；`core/rewind.py` 仅保留存储/文件回退部分。

搬迁时做了三处适配：`install(cls)` 的 monkey-patch 改成 `parse_command()`；`display_queue` 改成 `emit` 回调；内联了原来从 `chatapp_common` 导入的 6 个恢复辅助函数。

## 4. 删前端时必须做的代码手术

| 位置 | 改动 |
|---|---|
| `agentmain.py` 的 `--reflect` 分支 | 删掉 `import frontends.hub` 整段，否则留下悬空依赖（原本在 try/except 里，不会崩但会静默失效） |
| `pyproject.toml` | 删 `[optional-dependencies]`、`packages = ["旧前端包"]`、`[project.scripts]`，否则 `pip install -e .` 会因 entry point 找不到模块而失败 |
| `pyproject.toml` 依赖 | `rich` 必须保留——`core/rewind.py` 用 `rich.cells` 计算显示宽度 |
| `.gitignore` | 上游是 `memory/*` 全部忽略 + 白名单放行；本仓库改为 **`memory/` 全部入库**，否则进化出的技能没有版本、不可回滚 |
| `core/modes.py` | 删掉 `/conductor` 入口与"发现 frontends 应用"的逻辑，只保留 `reflect/` 脚本发现 |
| 文档引用 | `memory/review_sop.md`、`memory/subagent.md`、`memory/tmwebdriver_sop.md` 中指向已删文件的名字同步改掉，避免"幽灵条目" |

## 5. 验证方式

裁剪后做了四层验证，全部通过：

1. `compileall` 全量编译；
2. 逐个 import 内核、`core/`、`engine/`、`memstore/`；
3. `ZicatAgent()` 实例化，确认 9 个工具与模型加载正常；
4. 真实端到端跑一次 `--func` 任务，确认模型能调用工具并落盘。

之后做注释中文化时又加了一层校验：用 tokenize 比较"代码 token 流"，确保只改了注释。

## 6. 想恢复某部分怎么办

所有被删内容都在 git 历史里：

```bash
git log --oneline -- frontends/          # 找删除前的最后一个 commit
git show <commit>:frontends/qtapp.py     # 取回单个文件
git checkout <commit> -- docs/           # 整目录恢复
```

注意：恢复前端会同时需要 `pyproject.toml` 里的可选依赖与 `agentmain.py` 里的 hub 接线，不要只把文件拷回来。
