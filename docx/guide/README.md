# zicatAgent 项目导读（guide 层）

> 本目录是 docx 四层文档中的**导读层**：面向理解的项目介绍、原理讲解、历史迁移评估与裁剪记录。
> 分工：**讲解看这里**；模块契约与现状看 [arch](../arch/v1/index.md)、版本目标看 [dev](../dev/todolist.md)、版本差异看 [explain](../explain/todolist.md)。
> 新的开发事实写入 arch/dev/explain，不写本层；本层只在与代码脱节时更新。
> 约定见 [00-总览/20-目录结构与约定](00-总览/20-目录结构与约定.md)。

## 怎么读

- **第一次接触**：按 00 → 10 → 20 → 30 的顺序读。
- **要改代码**：直接跳到对应模块的 `00-*` 总览，需要行号级细节再看 `10-*` 实现细节。
- **要基于它做二次开发**：先读 [70-二次开发/00-裁剪记录](70-二次开发/00-裁剪记录.md)。

## 维护规则

1. 新增文档放在对应模块目录下，按 `00-`、`10-`、`20-` 递增命名。
2. 一个模块的文档只讲这个模块，不要混放别的内容。
3. 文档里引用代码请写成 `文件:行号`，方便随代码变动核对。
4. 判断标准：**会被 Agent 运行时读取的内容**（`memory/*.md`、`assets/*.txt`）不是文档，不要搬进本目录。
