# 项目简介

> 文档索引：[docs/README.md](../README.md)

## 这是什么

**zicatAgent** 是一个本地优先、可自演进的个人 Agent 执行内核：LangGraph 单引擎负责循环与状态，工具层负责操作系统与浏览器，SQLite 记忆库负责长期经验沉淀。

| 指标 | 数值 |
|---|---|
| 内核代码 | 6 个根文件，约 2,300 行（`agentmain` / `agent_types` / `mykey_loader` / `zicat` / `simphtml` / `TMWebDriver`） |
| 扩展模块 | `core/`（内核模块）、`engine/`（LangGraph 引擎）、`memstore/`（记忆库）、`ui/`（Web 前端）、`reflect/`（自动化） |
| 工具 | 16 个（9 个原子工具 + 7 个 `memory_*`） |
| 依赖 | requests / beautifulsoup4 / bottle / simple-websocket-server + langgraph / langchain-core / langchain-openai / langgraph-checkpoint-sqlite |
| 记忆 | SQLite `memory/memory.db`（L1–L4），文件保留 L0/导出/备份 |
| 入口 | Web UI（React）；无 GUI 桌面壳 / IM bot |

## 它主打的三件事

1. **单引擎 + 可恢复**：LangGraph 状态图 + SQLite 检查点，会话可跨进程恢复、可回退；消息只追加。
2. **自进化记忆**：任务经验沉淀成 `memory/kb/` 下的 SOP 与脚本，靠 L1 索引在后续任务中被召回；记忆库版本/事件可审计。
3. **强执行力**：通过"每步重锚 + 周期纪律注入 + 坏响应检测 + 硬超时"把模型的执行稳定性拉高，而不是靠更大的上下文。

## 一句话理解它的设计

> 它把"上下文"从「要记住什么」变成「每一轮要重新告诉它什么」。

接受这个前提之后：记忆可以外置到记忆库、历史可以折叠但只追加、模型可以随时切换，系统复杂度从"维护巨大状态"降到"写好每轮提示词 + 管好每轮视图"。

## 快速开始

```bash
python -m pip install -e .
copy mykey_template.py mykey.py     # 填 apibase / apikey / model
python agentmain.py
```
