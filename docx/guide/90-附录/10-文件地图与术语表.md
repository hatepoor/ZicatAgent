## 术语表

| 术语 | 含义 |
|---|---|
| **重锚（re-anchor）** | 每轮把工作记忆/历史/轮次重新拼进 prompt 的动作 |
| **L1 索引** | 从 `memory_items` 动态渲染；库不可用时回退 `memory/l1_fallback.txt` |
| **存在性索引** | 只声明"有这么个能力"，不写怎么用，让模型自己读 |
| **工作记忆 / key_info** | 覆盖式便签，每轮注入，跨任务继承并老化 |
| **闸门 A / B** | 两道上下文裁剪：标签折叠 / 消息头删 |
| **reflect 模式** | 用一个 `check()` 函数轮询驱动的无人值守自启动 |
| **TMWebDriver** | 本地 WS + Chrome 扩展，操作真实浏览器的方案 |
| **`<summary>`** | 每轮强制的一行"物理快照"，构成跨轮记忆骨架 |
| **SOP** | 沉淀在 `memory/` 的可复用流程文件，Agent 运行时读取执行 |
| **BBS** | Goal Team 用的公告板服务，worker 通过它领任务 |
