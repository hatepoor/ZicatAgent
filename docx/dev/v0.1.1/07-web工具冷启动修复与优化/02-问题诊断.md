# 02 · 问题诊断:web_scan"没通"

> 日期:2026-10-28 · 现象:`web_scan` 报"没有可用的浏览器标签页,查L3记忆分析原因"

## 1. 现象与初判

"没通"按报错形态分三类,对应不同故障点:

| 报错形态 | 故障点 |
|---|---|
| "没有可用的浏览器标签页" | master 活着,扩展没连上(未装/被停/浏览器没开/页面不可注入/等待窗口不够) |
| 其他异常(format_error) | 端口被占、假活 master、OSError 10048 等 |
| `No response data in 15s` | 连上了但注入执行超时(后台标签页节流、页面跳转) |

## 2. 诊断实验与数据

环境:用户默认浏览器 MSEdgeHTM(Edge,28 进程在跑),Chrome 未运行;初始时 18765/18766 端口空闲、无 master、扩展未连。

| # | 实验 | 结果 | 结论 |
|---|---|---|---|
| E1 | 纯起 master,每 5s 打印 sessions,观察 90s | 90s 内 sessions 恒为 0 | **扩展未装/未启用时等多久都没用**——等待窗口不是第一根因 |
| E2 | 修复前冷启动 5 次(无扩展环境,系统 python) | 0/5,16.6s 失败 | 另暴露:系统 python 缺 simple_websocket_server,必须用 `.venv` |
| E3 | 用 `.venv` 重跑 5 次(仍无扩展) | 0/5,均 16.5s(14s 窗口 + 开销) | 旧窗口 7×2s、第 10s 才 `webbrowser.open`,报错无指引 |
| E4 | 独立 profile + `--load-extension` 起带扩展 Edge,同环境重测 5 次 | **5/5,均 7.2s** | 扩展重连常态 5~6s(扩展端 alarm ~5s 一轮),14s 窗口"能过但太紧" |

## 3. 根因排序

1. **浏览器扩展未安装/被停用**(主因,日常场景):本机默认浏览器为 Edge,扩展此前未装入;无扩展时一切等待必然失败。
2. **等待窗口过紧**:每换 agent 进程,扩展需重连(5~6s 常态;alarms 被 clamp 或机器慢时更长);14s 窗口无余量。
3. **`is_remote` 一次性误判**:旧代码 `socket.socket().connect_ex((host, port+1))` 判断 18766 可连即走 remote 模式——socket 未 close(泄漏),且不验证对端是否真是活 master;假活时后续所有调用 `ConnectionError`。反之若 18765 被占,`WebSocketServer` 构造直接抛 OSError 10048;HTTP 服务在 daemon 线程中失败**静默**。
4. **报错不可执行**:"查L3记忆分析原因"对 agent 与用户都是死胡同,把确定性故障(未装扩展)引向了无效自查。

## 4. 排除项

- 端口冲突:诊断时 18765/18766 空闲(排除为本次主因,但作为工程隐患列入修复 ④ 与路线图 O7)。
- 代理/防火墙拦回环 WS:扩展成功连入(E4),排除。
- simphtml/BeautifulSoup 链路:E4 中 get_html 正常返回,排除。

## 5. 诊断方法沉淀(可复用)

```bash
# 1) master 与 session 状态一把梭(master 未起时为 curl exit 7)
curl -s -m 5 http://127.0.0.1:18766/link -X POST -d '{"cmd":"get_all_sessions"}'

# 2) 干净浏览器环境(独立 profile,不污染日常浏览器)
msedge --user-data-dir=temp/edge_test_profile \
       --load-extension=assets/tmwd_cdp_bridge \
       --no-first-run --no-default-browser-check https://example.com

# 3) 单次冷启动计时
.venv/Scripts/python.exe tests/manual_web_scan.py   # 输出单行 JSON:ok/time_s/msg/tabs

# 4) 测后清理(仅测试实例;PowerShell 内联 $_ 会被 bash 吞,wmic 已移除)
.venv/Scripts/python.exe -c "import psutil; [p.kill() for p in psutil.process_iter(['name','cmdline']) if p.info['name']=='msedge.exe' and p.info['cmdline'] and any('edge_test_profile' in c for c in p.info['cmdline'])]"
```
