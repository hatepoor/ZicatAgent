## 1. 改动清单

### ① `first_init_driver`:等待窗口与探测节奏重做

```python
# 旧:7 次 × sleep(2) = 14s;第 5 轮(i==4,即第 10s)才弹浏览器;get_all_sessions 异常会中断循环
for i in range(7):
    time.sleep(2)
    sess = driver.get_all_sessions()
    if len(sess) > 0: break
    if i == 4: webbrowser.open("https://example.com")

# 新:60s 窗口、每秒探测、第 3s 即弹浏览器(只弹一次)、探测异常吞掉继续等
def first_init_driver(max_wait=60):
    driver = TMWebDriver()
    opened = False
    for i in range(max_wait):
        time.sleep(1)
        try: sess = driver.get_all_sessions()
        except Exception: sess = []
        if len(sess) > 0: break
        if not opened and i >= 2:
            webbrowser.open("https://example.com"); opened = True
```

理由:扩展重连常态 5~6s,旧 14s 无余量;60s 覆盖 alarms 被 clamp 到 60s 的最坏情形;首次调用才付此成本,后续调用复用模块级 `driver`。

### ② 报错指引 `NO_TAB_HINT`

两处 `"没有可用的浏览器标签页，查L3记忆分析原因。"`(`_web_scan`/`_web_execute_js`)替换为:

> 没有可用的浏览器标签页:浏览器扩展(TMWD CDP Bridge)未连上 master。排查:1)浏览器已打开普通网页(chrome://页不可注入);2)扩展已加载且未停用(assets/tmwd_cdp_bridge);3)18765/18766端口未被残留进程占用;若仍失败,查L3记忆分析原因。

### ③ `TMWebDriver.__init__` / `_probe_remote`:端口自愈 + 修 socket 泄漏

```python
# 旧:一次性判定,socket 未 close,不验证对端
self.is_remote = socket.socket().connect_ex((host, port+1)) == 0

# 新:0.5s 超时探测 + close + /link ping 验证;假活 master → 自愈为本进程启动
def _probe_remote(self):
    probe = socket.socket(); probe.settimeout(0.5)
    try: alive = probe.connect_ex((self.host, self.port+1)) == 0
    finally: probe.close()
    if not alive: return False
    try:
        self._remote_cmd({"cmd": "get_all_sessions"}); return True
    except (ConnectionError, requests.exceptions.ConnectionError):
        safe_print(f"端口 {self.port+1} 已被占用但 master 无响应，本进程改为自行启动服务")
        return False
```

`self.remote` 提前到构造函数赋值,`_remote_cmd` 依赖它。兼容性:全项目仅 `tools/browser` 引用 TMWebDriver,影响面已核实。
